# RCA — Deploy run 8d5cb017-749f-40f7-aa60-d63c4dfe9d9f (email-audit-panel)

## Symptom
Redeploy failed at the `build_image` step. Cloud Build frontend compile aborted:

```
Failed to compile.
Attempted import error: 'authFetch' is not exported from './authFetch' (imported as 'AF').
error Command failed with exit code 1.
```

## Root cause (confirmed via source inspection in eph sandbox)
A named-import mismatch in the frontend source.

- `frontend/src/components/authFetch.js` exports ONLY a default:
  ```js
  export default function authFetch(url, opts = {}) { ... }
  ```
  There is **no named export** `authFetch`.

- `frontend/src/components/ComboPriceEdit.js` imports it as a namespace and then
  statically references a named member that does not exist:
  ```js
  import * as AF from './authFetch';           // line 2
  const doFetch = AF.authFetch || AF.default || fetch;   // line 5
  ```
  The static member access `AF.authFetch` makes webpack look for a named export
  `authFetch` on the module. It finds none (only `default`), so it emits the
  "Attempted import error: 'authFetch' is not exported from './authFetch'
  (imported as 'AF')" error. The production cloud build runs with CI=true, which
  promotes this warning to a hard failure → `exit status 1` → build_image fails.

All other call sites use the correct default import (`import authFetch from './authFetch'`); `ComboPriceEdit.js` is the only offender.

Note: this was verified statically (file contents + the exact error string match). A full `yarn install` + CRA build was not run in the sandbox because this large app would exceed the sandbox command timeout; the mechanism is deterministic and the error text matches exactly.

## Fix (Code — E1 to apply in app source)
Edit `frontend/src/components/ComboPriceEdit.js`. Either:

Option A (minimal): drop the non-existent named-export reference —
```js
import * as AF from './authFetch';
const doFetch = AF.default || fetch;
```

Option B (cleaner, matches every other file): use the default import directly —
```js
import authFetch from './authFetch';
const doFetch = authFetch;
```

Then redeploy. No manifest, secret, tier, or infra change is required.
