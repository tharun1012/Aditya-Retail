**New requirements from this session**:
- **Tax Calculation**: Delivery charges and other fees must be included in the GST calculation (18% inclusive).
- **Stock Management**:
    - When a Sales Order (SO) is created, stock should be blocked/reserved.
    - When the SO is converted to an Invoice, the reserved stock must be deducted.
    - When a Goods Receipt Note (GRN) is created, physical stock should be added.
- **Delivery Workflow Overhaul**:
    - Invoices (not Delivery Challans) should be assigned directly to the delivery person. The invoice itself will act as the delivery document.
    - The Delivery Challan (DC) should only be used for material transfers (e.g., store-to-store) where no invoice is generated. It should support E-way bill numbers.
- **Serial Number Tracking (E2E)**:
    - Serial numbers must be captured during GRN.
    - When creating an SO/Invoice, the user must be able to select from available serials or enter them manually. The system should not require serials for all products.
- **Customer Account Management**:
    - A customer account should be automatically created upon their first purchase if one doesn't already exist. Login details should be emailed to them.
- **Customer Dashboard Enhancements**:
    - Instead of a separate portal, the existing customer dashboard should be enhanced to include:
        - Product registration (using invoice/serial #) to track warranty.
        - Smart reminders for consumables (e.g., detergents, filters) based on the product.
        - An AI-powered feature for registering service complaints.
        - A quick-order feature for consumables.
        - Access to all past invoice copies.
