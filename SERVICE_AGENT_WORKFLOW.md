### **Step 1.1: Initial Contact**
```
Customer: "My Bosch washing machine is not working"

Service Agent (AI): "I'm here to help! I'll get your washing machine 
working as quickly as possible.

To diagnose this accurately, I need to understand a few details:

1️⃣ What's the exact model number? (Usually on a sticker inside the door)
2️⃣ What exactly is happening?
   - Not starting at all?
   - Starting but not working properly?
   - Showing an error?
3️⃣ When did this start?
4️⃣ Any error codes or blinking lights?"
```

**What Agent Does Behind the Scenes:**
- ✅ Activates Service mode
- ✅ Loads product knowledge base
- ✅ Initiates diagnostic decision tree
- ✅ Starts data collection
- ✅ Prepares troubleshooting protocols

## 🔧 PHASE 2: REMOTE TROUBLESHOOTING

### **Step 2.1: Systematic Diagnosis**
```
Service Agent: "Perfect, Rajesh! Let's get this sorted. The blinking 
red light usually indicates a safety lock or power issue.

Let's try these steps systematically:

**Step 1 - Power Reset:**
1. Unplug the machine from the wall socket
2. Wait for 60 seconds (this resets the control board)
3. Plug it back in
4. Try turning it on

Did that work?"
```

**What Agent Does:**
- ✅ Accesses knowledge base for model-specific issues
- ✅ Identifies "blinking red light" = door lock/safety issue
- ✅ Starts with simplest solution (power reset)
- ✅ Provides clear, numbered instructions
- ✅ Waits for customer response

---

### **Step 2.2: Progressive Troubleshooting**
```
Customer: "I tried that. The red light is still blinking."

Service Agent: "Understood. Let's move to the next step.

**Step 2 - Door Lock Check:**
The red light can indicate the door isn't locking properly.

1. Open the door completely
2. Check for any clothes stuck in the door seal
3. Close the door firmly - you should hear a clear 'CLICK'
4. The door lock light should turn solid/stop blinking
5. Try starting a cycle

What happened? Did you hear the click? Did the light change?"
```

**Agent's Decision Tree:**
```
Power Reset Failed
    ↓
Check Door Lock
    ↓
Check Water Supply
    ↓
Check Drain Filter
    ↓
If Still Failed → Escalate to Ticket
```

---

### **Step 2.3: Multiple Troubleshooting Attempts**
```
Customer: "The door clicks but the light is still blinking. 
I also notice there's some water in the drum from the last wash."

Service Agent: "Ah! That's the key detail! Water remaining in the drum 
often prevents the machine from starting (safety feature).

**Step 3 - Manual Drain:**
1. Locate the small drain filter door at bottom-right of machine
2. Place a shallow tray underneath to catch water
3. Slowly twist the drain filter cap counter-clockwise
4. Let water drain out (might be 1-2 liters)
5. Check for any coins, buttons, or debris in the filter
6. Clean the filter and screw it back tightly
7. Close the filter door
8. Try starting the machine now

This should resolve the issue! Let me know how it goes."
```

**What Agent Tracks:**
- ✅ Troubleshooting attempts: 3 steps
- ✅ Customer engagement: Active
- ✅ Issue complexity: Moderate
- ✅ Resolution probability: High (85%)

---

### **Step 2.4: Issue Resolved**
```
Customer: "Wow! That worked! The machine is starting now. 
There was a lot of water and some small stones in the filter!"

Service Agent: "Excellent news, Rajesh! 🎉 I'm glad we got it working!

Those stones likely came from pockets - they can block the drain. 
Here are some preventive tips:

💡 **Maintenance Tips:**
1. Check pockets before loading clothes
2. Clean the drain filter every 2-3 months
3. Run a drum clean cycle monthly (empty drum, hot water, detergent)
4. Leave the door slightly open after wash (prevents odor)

**Your Issue:** Blocked drain filter
**Status:** ✅ RESOLVED
**Time:** 8 minutes

Would you like me to email you the complete maintenance guide 
for your model?"
```

**Successful Resolution Path:**
```
Issue Reported
    ↓
3 Troubleshooting Steps
    ↓
Issue Resolved
    ↓
Preventive Tips Shared
    ↓
Follow-up Offered
    ↓
✅ Case Closed (No Ticket Needed)
```
